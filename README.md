# スカイライン・テクノロジーズ 企業サイト

架空のソフトウェア企業「スカイライン・テクノロジーズ（Skyline Technologies）」のコーポレートサイトです。
HTML・CSS・JavaScript を `index.html` 1ファイルにまとめた静的サイトで、ビルドやサーバーは不要です。

## サイトの構成

| セクション | 内容 |
| --- | --- |
| ヒーロー | キャッチコピーと「無料で相談する」ボタン |
| 実績 | 導入企業数・稼働率などの数字（スクロールでカウントアップ） |
| サービス | Skyline Cloud / Horizon Analytics / AeroFlow の3製品 |
| 私たちについて | 会社紹介と3つのバリュー |
| 導入事例 | 3社の導入効果 |
| お知らせ | ニュース一覧（ヘッダーのお知らせバーにも順番に表示） |
| お問い合わせ | 問い合わせフォーム（デモ用のため実際には送信されません） |

そのほかの特徴:

- スマートフォン表示に対応（幅 720px 以下でハンバーガーメニューに切り替わります）
- OS の設定に合わせてダークモードで表示されます
- 「視差効果を減らす」設定が有効な場合はアニメーションを止めます

## ブラウザで開く手順

### 方法1: ファイルを直接開く

1. エクスプローラーで `company-site` フォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザ（Chrome、Edge など）でサイトが表示されます。

別のブラウザで開きたい場合は、`index.html` を右クリックして「プログラムから開く」でブラウザを選ぶか、ブラウザのウィンドウに `index.html` をドラッグ＆ドロップしてください。

### 方法2: コマンドから開く

PowerShell で `company-site` フォルダに移動し、次のコマンドを実行します。

```powershell
start index.html
```

### 補足

- フォント（Noto Sans JP）は Google Fonts から読み込むため、インターネットに接続しているときに本来の見た目で表示されます。オフラインでも端末のフォントで表示されます。
- ファイルを編集したら、ブラウザを再読み込み（F5）すると変更が反映されます。
